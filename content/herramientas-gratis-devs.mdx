Hay herramientas que, una vez que las conoces, no puedes dejar de usar. Todas las de esta lista son **gratis**, funcionan desde el navegador y te ahorran bastante tiempo en el día a día.

Las he organizado por categoría, **¡guárdalas en tus favoritos!**

## Para datos y código

### IT Tools
[IT Tools](https://it-tools.tech/) es como una navaja suiza: más de 80 utilidades en una sola página. Generar UUIDs, codificar en Base64, convertir JSON a YAML, generar hashes, decodificar JWT... Todo en un solo lugar y es de código abierto.

### JSON Crack
[JSON Crack](https://jsoncrack.com/) convierte un JSON gigante en un diagrama visual que puedes explorar. Cuando una API te devuelve 2000 líneas de JSON anidado, esto te salva.

### Transform Tools
[Transform](https://transform.tools/) convierte entre formatos: JSON a TypeScript, JSON a Zod, HTML a JSX, SVG a componente de React y muchos más. Perfecto para no escribir tipos a mano.

### regex101
[regex101](https://regex101.com/) para probar expresiones regulares. Lo mejor es que te **explica** qué hace cada parte de tu regex, así que también sirve para aprender.

## Para colores y diseño

### Realtime Colors
[Realtime Colors](https://www.realtimecolors.com/) te muestra cómo se ve tu paleta de colores aplicada a una página real. Además exporta directamente a CSS o Tailwind.

### Coolors
[Coolors](https://coolors.co/) para generar paletas de colores. Presionas la barra espaciadora y te genera una nueva. Puedes bloquear los colores que te gustan y seguir generando.

### Excalidraw
[Excalidraw](https://excalidraw.com/) para hacer diagramas con estilo "dibujado a mano". Ideal para explicar la arquitectura de un proyecto o planificar antes de programar.

## Para iconos y logos

### Lucide
[Lucide](https://lucide.dev/) tiene más de 1500 iconos limpios y consistentes, con paquetes para React, Vue, Svelte y más. Es el que usa shadcn/ui por defecto.

### SVGL
[SVGL](https://svgl.app/) tiene los logos en SVG de casi cualquier marca o tecnología. ¿Necesitas el logo de React, Vercel o Discord para tu portafolio? Aquí está, listo para copiar.

## Para imágenes

### Squoosh
[Squoosh](https://squoosh.app/) comprime imágenes en el navegador (sin subirlas a ningún servidor). Puedes convertirlas a WebP o AVIF y ver la diferencia de calidad en vivo. Tu página va a cargar mucho más rápido.

### ray.so
[ray.so](https://ray.so/) para hacer capturas bonitas de tu código. Perfecto para compartir en redes sociales o en tu documentación.

## Para revisar tu web

### PageSpeed Insights
[PageSpeed Insights](https://pagespeed.web.dev/) analiza el rendimiento de tu página y te dice exactamente qué mejorar. Es de Google, así que también influye en tu SEO.

### Can I use
[Can I use](https://caniuse.com/) para saber si una función de CSS o JavaScript funciona en todos los navegadores antes de usarla.

### Bundlephobia
[Bundlephobia](https://bundlephobia.com/) te dice cuánto pesa una librería de npm **antes** de instalarla. Muchas veces te vas a sorprender.

## Conclusión

No necesitas instalar nada para tener un buen kit de herramientas, con el navegador basta. Mi recomendación: crea una carpeta de favoritos llamada **"Dev"** y mete todas estas ahí.

¿Usas alguna que no esté en la lista? ¡Déjamelo saber y la agrego!
